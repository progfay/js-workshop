# 数値

JavaScript の数値は `2`, `14`, `4353` のような整数も、
`3.14`, `1.5` のような小数も同じ `number` 型で表します。

数値は引用符で囲みません。囲むと文字列になってしまいます。

```js
const price = 100; // 数値
const text = "100"; // 文字列 (別物!)
```

## やってみよう

変数 `example` に整数 `123456789` を代入してください。

`console.log(example)` でデバッグ出力できます。
わざと `"123456789"` と引用符付きで実行してみると、テストケースの
エラーメッセージで数値と文字列の表示の違い（`"..."` の有無）が確認できます。
