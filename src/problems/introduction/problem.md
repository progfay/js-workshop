# はじめの一歩

このアプリでは、エディタにコードを書き、**実行**ボタンで採点します。

採点は「テストケースを1つずつ実行し、`throw` されなければ合格」という方式です。

- **テストケースはすべて公開されています**。各ケースを開くと、何をチェックしているかコードで確認できます。
- 失敗したケースにはエラーメッセージが表示されます。**メッセージを読む**のが上達への近道です。
- `console.log()` はデバッグ用として使えます。出力は実行結果のパネルに表示されます。
- 全テストに合格すると、その問題の**解説**が読めるようになります。

## やってみよう

文字列 `"hello"` を表す変数 `message` を定義してください。

```js
const message = "hello";
```

書けたら**実行**して、全テストケースが緑になれば正解です。
まずはわざと `"hello!"` などの違う値で実行してみて、
失敗したテストケースにどんなメッセージが出るかを見てみるのもおすすめです。
