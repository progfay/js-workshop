# 解説

```js
let total = 0;
const limit = 10;
for (let i = 0; i < limit; i++) {
  total += i;
}
// total -> 45  (0 + 1 + ... + 9)
```

`total` は再代入するので `let` で宣言します。`0` から `9` までの合計は `45` です。

もしテストで「`total` は 45 を期待しましたが 55 でした」と出たら、
条件を `i <= limit` と書いていて `10` まで足しています（よくあるミスです）。
ループの中に `console.log(i, total)` を置くと、1周ごとの値の変化を観察できます。
